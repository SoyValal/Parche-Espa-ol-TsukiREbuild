# 📖 Traducción al Español — [TsukiRebuild]

Este repositorio contiene los archivos de traducción al español de **[Nombre de la Novela Visual]**, un proyecto desarrollado con el objetivo de traer esta obra completa y con una adaptación literaria fiel al público hispanohablante.

## 📊 Estado del Proyecto
* **Progreso actual:** ~11,000 / 43,960 líneas traducidas (25% completado).
* **Estado:** En desarrollo activo (en proceso de traducción y revisión de estilo).

## 🛠️ Metodología y Herramientas
Para procesar el volumen masivo de diálogos y mantener la coherencia narrativa, los saltos de línea y la estructura original de los archivos del juego sin errores de formato, este proyecto utiliza mi herramienta de traducción automatizada:

👉 **[VN-JSON-Local-Translator](https://github.com/SoyValal/VN-JSON-Local-Translator)**

Gracias a este flujo de trabajo híbrido (combinando modelos de IA en la nube y ejecución local mediante Ollama con sistema de *checkpoints* y validación estricta de JSON), ha sido posible avanzar las primeras 11,000 líneas conservando el tono literario de la obra y permitiendo realizar pruebas funcionales directamente dentro del juego.

## 🚀 Cómo probar el avance actual
1. Descarga el archivo JSON traducido más reciente desde este repositorio.
2. Haz una copia de seguridad de los archivos originales de tu juego.
3. Reemplaza el archivo de texto en la carpeta de datos de la novela visual.
4. *(Nota: Las líneas posteriores a la 11,000 aparecerán temporalmente en su idioma original mientras avanza la traducción).*
